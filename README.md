# Castle Opening Level — top-down 3/4 action-RPG (Godot 4.4)

Playable opening chapter built from `castle_crosscode_rework_pack` (23 individual assets + 2 overview references).
Forest/river approach -> gatehouse/drawbridge -> courtyard -> keep / library / chapel / great hall / kitchen / barracks ->
service yard (stable, blacksmith) -> secret descent (well **or** pantry) -> cistern, crypt/prison junction, loop, hidden
smuggler's tunnel -> surface exit beyond the castle wall -> return.

* Run: open the folder in Godot 4.4.x (GL Compatibility) and press F5 (main scene `Scenes/Exterior/Approach.tscn`).
