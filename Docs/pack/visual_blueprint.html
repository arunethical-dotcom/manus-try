03 / Art integration

Depth and pixel-art readability

Use footpoint/Y sorting for actors and props. Keep building front edges and roof planes on deliberate layers. Verify alpha edges, downscale uniformly, and use nearest-neighbor filtering. Test ground textures for repeat seams before tiling.

04 / Player scale

Gameplay camera scale anchor

Character reference: approximately 64 game pixels tall. Calibrate path width, entrances, stairs, collisions and prop readability against the actual in-project player, then keep that scale consistent.
